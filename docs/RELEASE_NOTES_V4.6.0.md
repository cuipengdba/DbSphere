# DbSphere v4.6.0 备份恢复演练

- PostgreSQL 资产支持恢复演练申请、独立审批、隔离目标核对和结果登记。原始采样、演练签收报告和原风险事件可相互定位。
- 支持查看 pgBackRest 备份年龄、备份依赖和 WAL 缺口。签收报告显示事务核验和 RPO/RTO 实测差异。
- Linux amd64 和 arm64 三类离线包附带 pgBackRest 2.60.1 静态工具及许可证。数据库主机可单独一键离线安装工具。
