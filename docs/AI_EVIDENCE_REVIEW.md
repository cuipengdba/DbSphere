# 事件证据助手

在 **根因与证据 → 证据助手** 查看规则核查。接入模型后，管理员和值班员可在当前事件请求审核。候选解释、反证与核查建议逐条引用证据。模型缺少核查项时，系统沿用已验证的引用补充规则核查，并标明来源。点击引用可定位事件时间线，带采样标识的记录可打开原始采样。获准查看事件的账号可以查看该事件的审核结果。

展开 **预览送审证据** 可以核对将提交的记录。证据最多 18 条和 8,000 字节，包含证据 ID、类型、时间、采样 ID 和允许传输的数值字段。可附一条最多 400 字的核查问题。问题正文随请求发送，请勿在问题中填写凭据或 SQL 原文。若预览后的证据或配置发生变化，页面会重新读取证据供确认。组织每日请求额度沿用现有 AI 预算，审计记录输入字节数、证据数量、模型、引用和结论。模型输出中每条引用必须来自实际送审的证据，并在保存前核对其事件归属。

未接模型、模型不可用、引用验证失败或预算用完时，可查看同一事件的规则核查。证据不足在调用模型前反馈。证据助手沿用现有只读诊断权限，受控作业继续使用申请、审批和执行流程。

通过 **设置 → 模型接入** 管理模型。审核超时默认 28 秒，可设为 1–120 秒。兼容 JSON Schema 的接口可启用结构化响应。部署配置见[模型接入说明](AI_INTEGRATION.md)。
