# DbSphere v2.20–v2.24 开发规划

这五个版本以值班工作流为主线。管理员先确认日志是否完整到达，再从已有故障事件定位同一实例的日志，核对应用或 SQL 的异常，最后记录调优结果并验证证据归档。Go 服务端、静态浏览器界面、PostgreSQL 18 长期存储、深浅主题和双架构一键离线交付沿用现有架构。

| 版本 | 开发内容 | 发布验收 |
| --- | --- | --- |
| v2.20 | **日志导入任务中心。** 跨批次查看上传进度、待解析时间、重试次数和失败原因。按状态分页，点击返回原批次。显示当前占用的队列配额。管理员可以取消尚未提交的上传，释放分块和配额并留下审计。 | 在 PostgreSQL 18 中验证断点续传、隔离、取消未提交任务、保留已提交日志及队列分页。补做金仓 V9、达梦 DM8 的本机原生日志复验，并按实测范围记录结果。 |
| v2.21 | **从原事件查找同窗日志。** 事件页按已核对的资产 ID 和时间窗检索日志，展示应用、会话、错误码、等待和 SQL 指纹。区分仅仅同窗的线索与已经采纳的证据。管理员可在原事件下采纳日志并直接查看受审计的原文。 | 同资产和同窗候选能挂到原事件，跨资产、跨组织及过期原文保持各自的权限和状态。重复操作沿用已有证据。 |
| v2.22 | **应用与 SQL 性能下钻。** 从慢 SQL 或应用矩阵进入分时耗时、延迟分布和样本覆盖，同一筛选贯穿报表和明细。显示完整日志、慢日志和抽样口径。直达代表记录、相关锁等待和调查入口。 | 用包含快慢 SQL、无耗时记录和两个应用的混合日志核对统计、过滤和原文。 |
| v2.23 | **调优复测结果。** 在原调查下为一次调优登记基线、复测批次与目标阈值。复用批次对比口径，记录是否达标及判定依据。输出带原事件、两侧证据编号和复测指标的脱敏结果。 | 覆盖达标、回退、覆盖不足三种结果，并校验同一事件、调查和证据路径。 |
| v2.24 | **归档容量与保留验收。** 保存策略前预览预计到期文件、空间及被调查保留的归档，核对归档使用量。提供分页的到期和完整性视图，逐项查看原事件是否保留。 | 用 PostgreSQL 18 验证策略预览、到期清理、调查引用保护和备份恢复。发布标准版与 Grafana 增强版的 Linux amd64、arm64 一键离线包。 |

每个小版本独立测试、校验产物并发布，下一版沿用上一正式版作为离线升级基线。实机和样例验收分别记录。模型接入保持可选，采集、规则分析和原文回溯可以离线使用。
