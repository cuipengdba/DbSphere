# DbSphere v4.9.0

本版交付企业自托管的离线授权与签名安装介质。

- 平台管理员可在「系统状态 → 部署授权」核对部署编号、授权期限、续期序号、资产及站点用量，并导入签名授权。按部署编号校验，可对同一部署续期和扩容。 [企业自托管交付](ENTERPRISE_SUBSCRIPTION.md)
- 在授权到期或时钟异常后继续监控已有资产，保留告警、历史证据与导出。单资产新增、批量应用及新站点登记按有效授权检查容量。
- 为 Linux amd64 与 arm64 的标准容器、Grafana 增强及 systemd 离线包交付 Ed25519 发布签名、可信公钥和 `SHA256SUMS`。先核对签名并核对所选安装包的摘要，再运行 `.run`。 [离线部署](OFFLINE_DEPLOYMENT.md#执行前核对发布签名)

升级时备份 PG18 监控库，保留原环境和主密钥。社区部署可沿用现有配置。测试数据源范围及部署条件见详细矩阵。 [支持矩阵](SUPPORT_MATRIX.md)
