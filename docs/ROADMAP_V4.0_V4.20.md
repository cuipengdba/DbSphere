## 产品定位与首批客户

DbSphere 面向需要在内网运维多种数据库的 DBA 和 SRE 团队。首批目标客户建议为已有 PostgreSQL、MySQL、Redis 或国产数据库、管理约 50–300 个资产的企业平台运维团队。运维负责人负责试点签收，安全团队核对权限和数据流，采购及预算负责人核对交付与支持条款。

客户现场演示用一条实际流程串起交付价值。导入资产并核对首采，模拟一次数据库锁等待或复制延迟，从告警进入事件，打开原始证据，登记处置与恢复，再导出可供交接的报告。现有版本已经具备批量接入、跨层证据、工单回执和独立监控库恢复核对能力。后续版本补齐客户自助验收、数据治理、跨网段部署和长期服务。[项目首页](https://github.com/cuipengdba/DbSphere) · [事件调查](INCIDENT_INVESTIGATION.md) · [外部运维接入](OPERATIONS_INTEGRATION.md) · [历史存储](HISTORY_STORAGE.md)

## v4.0.0–v4.9.0 试点到商业交付

### v4.0.0 客户试点交付

- [ ] 新增部署预检，检查主机架构、磁盘、端口、独立 PG18 连通性和目标库监控权限，给出可操作的修正建议。
- [ ] 在现有批量接入流程增加资产验收清单，展示引擎版本、首采指标、权限缺口和原始样本。修正配置后对同一资产复检，保留首次结果。
- [ ] 增加脱敏支持包导出与预览，列出安装信息、采集状态和选定事件摘要，使用字段白名单生成文件清单。
- [ ] 制作可重置的演示数据、中文安装与故障演示手册，为离线包生成软件物料清单（SBOM）与源码版本记录。

**97 验收场景**

在干净环境部署，使用 PostgreSQL 18、MySQL 8.4、Redis 6.2 和一个已支持国产库演练首采、权限不足和复检。核对支持包脱敏、原始证据回链和 v3.20.0 升级回滚。记录人工排查与规则诊断用时，作为后续 AI 效果对照。

**客户交付物**

固定范围试点说明、资产验收报告和签收模板，写清验收资产、场景、双方职责和支持时段。 [试点验收手册](PILOT_ACCEPTANCE.md)

- [ ] 完善「系统 → AI 模型接入」，支持本地推理与兼容 Chat Completions 的客户网关，管理模型 ID、证书、密钥引用、组织范围和独立启停。
- [ ] 增加固定测试文本的连通性检查、调用预算与错误说明。记录经过实测的模型名称、端点版本、运行硬件和联网要求。

在两个网络隔离区验证中心无法直连的数据库仍可采集，覆盖断连 30 分钟、缓冲用满、重复补送和证书吊销。用真实本地模型验收断网分析，并验证兼容网关鉴权、错误证书、超时和额度耗尽后的规则回退。 [模型验收详情](#ai-独立接入与辅助分析)

### v4.3.0 SQL 性能退化与 AI 辅助分析

- [ ] 增加组织级 SQL 文本保留配置，核对原文可见权限和采集额外开销。

### 证据、权限与验收标准

- 手动分析从当前事件生成脱敏快照，页面展示将发往哪个模型以及哪些字段可发送。对远端端点按组织显式启用，并校验 HTTPS 来源和证书。发送字段使用白名单。默认发送指标、时间与受控证据标识，凭据、完整 SQL 和日志内容留在客户环境。日志和手册按参考资料读取，工具只开放当前事件的固定只读查询，沿用操作者的组织及资产权限。
- 输出以同一事件 ID 记录候选根因、证据、反证、缺口和建议。每个引用由服务端校验所属事件、权限与发送范围。已核对的调用关系、同期指标和缺采在页面分别标注。启停服务、改库、切换与恢复由现有人工审批和作业体系负责。
- 版本门槛包括已保存结果的引用校验、跨组织隔离、敏感字段脱敏，以及停用模型、断网、超时、预算耗尽和授权到期时的规则回退。质量评估使用固定用例，记录规则、模型、提示词和证据来源版本。建议在试点中验证同场景排查耗时、有效结论比例与单次成本，按实测值确定对客户的验收指标。
- AI 分析使用独立队列、并发上限和资源预算。发布前在 97 对照模型停用、正常响应和请求积压三种工况的采集完成率、告警时延及模型用量。验收报告记录各项实测结果和推理服务硬件条件。
- 企业版支持平台接入客户自带模型或经授权的兼容网关。用量记录请求次数、输入和输出 token、耗时及结果，模型未返回用量时注明估算口径。镜像和模型权重独立选配，随客户部署环境及各自许可交付。基础离线包可在无模型和无外网条件下完整运行采集、监控、告警和规则诊断。
