- 资产监控大屏的 12 张趋势图支持点击放大，鼠标、触屏和键盘可以打开同一张图。放大后沿用当前组织、环境、集群、实例和时段。

使用真实 Go 服务、PostgreSQL 18 和浏览器验证页面操作。含数据的场景使用隔离的测试资产和事件走正式 API。沿用现有 PostgreSQL、Kubernetes、Grafana、离线部署和升级回滚验收，并记录每项实际执行范围及结果。

### 验收执行

复测逐个操作入口，校验选中状态、路由、持久化结果、下载文件或原始证据 ID。筛选和翻页准备足量记录。写入及删除操作只使用本轮隔离测试数据。依赖额外组件或专用账号的路径由对应环境验收，并记录实际接入状态。

| 页面 | 浏览器操作与结果 |
| --- | --- |
| 登录和导航 | 错误凭据提示、管理员及授权账号登录、角色禁用项、退出、主题、版本号与页面返回 |
| 大屏和总览 | 12 张图表、采样时段、菜单与游标、时间选区、全屏、实例跳转和资产分页 |
| 工作台和实时观测 | 九个实例专题、范围修改与取消、实时指标选择、夜览、暂停、对比、全屏、存储模式与自定义时段、Grafana 返回及重试 |
| 资产 | 录入、编辑与取消、连接采集、读取资产详情、导出体检、清单预览和应用、分批探测、删除确认和分页 |
| 告警和巡检 | 规则与根因版本保存、历史规则回放、维护窗撤销、巡检计划及模板、执行与重跑、Markdown 和 HTML 报告 |
| 日志和事件 | 项目、实例、批次、上传与取消、全景筛选、跨批次证据、重建索引、复测、事件确认与处置、分享与撤销、事件报告、原文回链、归档预览与校验 |
| 系统 | 长期存储、保留策略、采集队列及覆盖报告、平台副本、组织、团队和账号保存、凭据轮换、授权导出和操作记录 |

发布前修复上述验收发现的交互问题，复跑受影响用例。按 Linux amd64 和 arm64 验证一键离线包、Go 静态服务和 systemd 安装包，校验产物 SHA-256 后发布。
