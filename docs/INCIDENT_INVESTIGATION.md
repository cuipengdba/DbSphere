# 事件调查工作台

从「问题事件」打开告警。在首屏核对事件 ID、实例、已登记的集群、可观测的数据库和事件状态。「同一时间窗」切换故障前、触发时及恢复后，按应用、数据库、连接池或基础设施查看该时间窗内已取得的证据。

打开等待趋势、锁树或环境趋势时，保留该事件 ID 和当前阶段的时间窗。返回事件可继续检查同一阶段。在增强包中可从事件进入已配置的 Grafana 专题。

对于有原始锁等待告警样本的事件，「查看阻塞者原始采样」直接打开已观察到的等待 PID 与阻塞 PID。会话未提供 Query ID 时显示采样范围。时间相关、标识不符和缺采依照实际证据显示。

「下载当前证据复盘」导出已选阶段、证据层、原始样本引用和相应人工复核摘要。完整时间线和原有事件报告仍可从同一事件获取。
