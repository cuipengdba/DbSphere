# Go 版可选 AI 诊断接入

**模型接入可选。** PostgreSQL、Linux 和 Kubernetes 采集、告警、巡检和规则根因分析均可离线运行。平台管理员与有事件权限的值班员可在证据助手中预览数据、填写核查问题，再提交模型审核。只读账号可查看事件及其审核结果。模型建议始终作为证据核查的输入，变更继续通过现有审批。

无模型预警包含 PostgreSQL 数据库约 24 小时实际增长速率、Linux 文件系统使用率和 Kubernetes PVC 使用率规则。数据库增长规则需 PG18 中 23–25 小时前的有效基线，默认持续 120 秒达到 10 GiB/日才触发；证据保留基线样本 ID。它仅说明数据库大小增长较快，不表示目标磁盘将满。没有可用基线或 PVC 实际用量时，相关信号保持未知。

## 配置

平台管理员在 **系统状态 → 模型接入** 填写兼容 Chat Completions 的完整地址与模型名称。密钥可选，保存后由平台主密钥加密并写入 PostgreSQL 18。连通性测试仅发送固定测试文本。保存、停用和恢复环境配置在副本间生效。更换地址时请为新地址输入所需密钥。

Go 进程或 Go Compose 也可通过环境文件提供默认配置。

```dotenv
DBSPHERE_AI_CHAT_URL=https://your-model-endpoint.example/v1/chat/completions
DBSPHERE_AI_MODEL=your-model-name
DBSPHERE_AI_API_KEY=replace-with-provider-token
DBSPHERE_AI_ALLOW_REMOTE=true
DBSPHERE_AI_ALLOWED_ORIGINS=https://your-model-endpoint.example
DBSPHERE_AI_DAILY_LIMIT=20
DBSPHERE_AI_AUTO_SUMMARY=false
```

接口使用兼容 `POST /chat/completions` 的非流式 JSON 请求。网页新增远端地址时，部署端须设置 `DBSPHERE_AI_ALLOW_REMOTE=true`，并在 `DBSPHERE_AI_ALLOWED_ORIGINS` 中加入该 HTTPS 来源。多个来源用逗号分隔，非默认端口须写明。已配置的环境变量模型地址自动授权其 HTTPS 来源。Go Compose 中的 `127.0.0.1` 指 DbSphere 容器自身。远端模型需要 HTTPS。脱网部署可选同一网络命名空间内的推理服务，并预先准备镜像和权重。

## 发送内容与结果边界

手动审核的请求与返回内容见[事件证据助手](AI_EVIDENCE_REVIEW.md)。早期摘要和提问 API 保持兼容。下列说明适用于兼容 API 和自动摘要。

在页面启用自动摘要，或通过 `DBSPHERE_AI_AUTO_SUMMARY=true` 设置默认行为。Go 后台每分钟最多选取 5 个最近 24 小时的严重开放事件，每个事件最多自动分析一次，与手动审核共用每日预算。校验后的摘要、检查建议和证据 ID 写入同一个事件的时间线与复盘报告，标为待人工核验。

- 发送同一事件 ID 的受控复盘摘要，最多约 12 KiB。包含事件状态、根因候选、证据 ID、样本 ID 和信号缺口；资产名称、应用服务名、人工备注和原始 SQL/参数不发送。外部模型调用仍可能暴露事件元数据，仅应在获得授权后启用。
- 模型必须返回 `summary`、`evidenceIds`、`uncertainty` 和 `suggestedChecks` 的 JSON。服务端校验引用的证据 ID 必须属于当前事件，拒绝虚构或重复 ID。结果在页面标记为“待人工核验”，不直接写成确定根因。
- 单次调用最长 12 秒，响应上限 32 KiB，同一事件 30 秒内最多请求一次。失败、超时或格式不合要求时，页面仍可使用确定性规则和原始证据。
- 事件问答最多 400 字，仅将问题和同一事件已脱敏、最多 12 KiB 的证据包发给模型；回答仍必须引用该事件实际出现在证据包中的 ID，保留不确定性并标记待人工核验。问题正文和手动回答不落库；同事件只记录模型、摘要/提问类型、成功或失败、引用证据 ID。由于问题也会发往配置的模型，管理员应避免在问题中输入账号、SQL 文本或其他敏感信息。
- 每 UTC 自然日默认最多发起 20 次模型调用，可用 `DBSPHERE_AI_DAILY_LIMIT` 设为 1–1000。PG18 在模型请求前原子预留并审计额度，成功、失败和服务重启后的调用都计入上限；达到上限返回 HTTP 429，规则诊断与采集不受影响。跨实例共用同一个 PG18 预算。
- PG18 的该事件证据时间线记录模型名、调用成功/失败及引用的证据 ID；手动分析不保存模型回复。启用自动摘要时，仅保存经过格式、长度和证据 ID 校验的建议字段，不保存完整请求、原始模型响应或 API Key。后续模型调用的证据包排除先前 AI 建议，避免模型自我引用。生产模型与预警效果仍需验收。
- 模型调用审计与事件证据同库保留。可选 `DBSPHERE_EVENT_RETENTION_DAYS=180` 限量清理满足条件的已结事件及其 AI 记录；开放事件、未完成通知和巡检关联事件保留更久。当前不提供独立的 AI 审计保留期。清理前应备份 PG18。关闭 AI 外发可不配置模型地址，或移除模型环境变量后重启；已保存的审计遵从事件保留规则。

## 验收范围

单元与 PG18 实库测试覆盖禁用默认值、HTTPS 远端显式开启、本机模拟模型、超时、虚构证据 ID 拒绝、问答长度、鉴权/CSRF、共享预算与同一事件 ID 的调用审计。真实外部模型服务、提前预测故障的 AI 预警和生产效果尚未验收；自动摘要只在严重规则告警已触发后提供建议。
