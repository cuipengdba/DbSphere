# DbSphere v4.7.0 服务报告与事件复盘

- 按客户、服务和资产组计算观测可用率、故障、计划维护、缺采及容量趋势。报告支持保存、人工签收、文本导出和原始样本回查。
- 按组织和告警组配置初始通知、关键告警升级和等待时限。Webhook 包含投递 ID 和原事件入口。
- 在同一事件保存复盘修订。可用 AI 生成带证据引用的待核对草稿，由人工编辑、驳回或签收归档。规则报告独立运行。
- 提供 Linux amd64 和 arm64 的标准容器包、Grafana 增强包及原生 systemd 一键安装包，以及校验清单。
