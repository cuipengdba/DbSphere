# DbSphere v2.14 资产监控大屏规划

登录后默认进入全域资产监控大屏。值班人员在同一屏看清哪些主机已纳管、上面运行哪些数据库、哪些对象需要立刻处理。异常入口沿用 v2.13 的事件 ID、时间窗和原始证据关联。

## 首屏布局

| 区域 | 页面内容 |
| --- | --- |
| 顶部状态栏 | 组织、环境、集群、时间窗、最近更新和暂停。显示可见主机数、数据库实例数、处理中异常数及缺采对象数。默认最近 1 小时，保留现有筛选和固定时间窗。 |
| 中央资产视图 | 按环境与集群展示主机图标和数据库卡片。已核实的「主机或 Kubernetes 节点 → 实例」关系用连线表达。同一主机只展示一次，可在节点下看到多个数据库及主库、备库、单实例等角色。 |
| 右侧优先处理 | 首屏显示最高优先级事件及受影响对象、持续时间和主要信号。点击事件进入对应调查页。点击主机或数据库卡片时，同时高亮已确认的依赖和相关异常。 |
| 底部关键趋势 | 默认显示十二张近 1 小时图表。主机侧展示 CPU 与内存、磁盘吞吐、网络收发和磁盘延迟。数据库侧展示连接占用、事务吞吐、SQL 平均耗时、等待会话、长事务、主备回放差距和 PgBouncer 排队。容器实例展示 Active file 与 Inactive file。每张图显示最新值及单位，故障、变更和恢复标记对齐到同一时间轴。 |

## 开发任务

- [ ] **14-01 登录与大屏外观**　升级默认总览，保留已分享的监控和事件直达链接。采用蓝黑底、冷色刻度、醒目的监控数字和一致的主机、数据库、容器图标。状态同时用文字与颜色区分。光效集中在当前异常、已选对象和观测到的依赖，动效限于状态变化和回放。提供一键全屏、暂停和主题切换，遵循减少动画偏好。
- [ ] **14-02 主机与数据库状态**　主机卡显示 CPU、内存和已采集的磁盘 I/O，并标记数据来源与采样时间。数据库卡显示可用性、角色、连接占用、阻塞或等待，支持在详情里查看 TPS、复制差距和容器文件缓存。已纳管但暂时失联的对象继续留在视图。
- [ ] **14-03 主机身份与租户范围**　服务端先按用户权限及组织、环境、集群筛选，再汇总对象与告警。Linux 主机按已核实的采集身份或资产关联去重，Kubernetes 节点按集群身份和节点 UID 优先核对。已确认归属的容器显示在其节点下。已纳管但尚未关联数据库的主机有独立位置。缺少身份或采集证据时标记「未关联」或「缺采」。
- [ ] **14-04 事件调查入口**　复用实时快照、事件优先级与调查工作台。首屏异常可以打开原有事件，保留事件 ID、对象、选区和游标。存在直接证据时，点击异常和原始采样两次操作即可核对证据。Grafana 专题按实际就绪状态展示入口，原生首屏读取 DbSphere 采样与事件。
- [ ] **14-05 十二张关键趋势图**　宽屏底部采用四列三行，窄窗口按宽度重排。图表标明主机、实例或容器，点选资产时整组联动。网络用接收和发送吞吐量，磁盘延迟按已确认设备的读写耗时增量分别除以相应完成次数，SQL 平均耗时按可比较快照中的执行耗时增量除以执行次数增量。标明 SQL 统计采样覆盖、长事务阈值、PgBouncer 所属实例和文件缓存容器。设备归属、采集覆盖或计数连续性不足时标明原因并保留曲线缺口。所有图共享时间窗和事件游标，固定选区可以进入相应专题再返回。
- [ ] **14-06 默认偏好**　登录后默认深色，记住用户主动选择的主题。首页左下角去掉「PostgreSQL 14–19」字样，继续显示服务端构建版本号。新部署的默认管理员为 `admin`，初始密码为 `1234567890123`，按现有初始化流程设置正式密码。
- [ ] **14-07 离线交付**　Go 服务继续内嵌静态页面、图标和图表。标准和增强一键离线包均提供新大屏，验收 Linux amd64 与 arm64 从 v2.13 升级、PostgreSQL 18 历史保留和站内专题回链。
- [ ] **14-08 数据加载与状态**　首屏批量读取范围汇总、当期状态和最新异常，十二张图共用一次所选范围的趋势读取，宿主细节和完整拓扑随下钻加载。设备较多时分组并分页，显示可见范围总数。断线期间保留最后已确认值和采集时间，恢复后继续当前组织、对象和时间窗。相邻采样缺口在图上断开。

## 验收目标

- 1366×768 登录首屏可辨认主机、数据库、最高优先级异常和调查入口。1920×1080 全屏能同时查看资产、异常和十二张趋势图。点击主机或实例后校对图表对象、最新值及事件标记确实来自同一时间窗，键盘可退出全屏并继续原选区。
- 用同机多实例、Docker 与 Kubernetes 部署验证已核实的归属关系。重复主机不重复计数，同名不同节点保持独立。无可见资产时展示纳管入口或权限范围，已有资产缺采时保留名称和状态。
- 演练主机失联、PostgreSQL 锁阻塞和采集断线。确认高优先级事件在首屏可见，同事件证据链可复核，回到大屏后仍是原时间窗和原对象。补验 Grafana 停止时原生大屏加载正常。
- 以 100 个数据库实例和 20 台已关联主机作为首屏负载验收样例，记录 API 请求量和首个可操作画面耗时。切换范围时验证旧响应不会覆盖新画面，分页或下钻只读取可见范围的数据。
- 新浏览器首次登录默认深色，主动切换浅色后刷新和再次登录仍使用所选主题。左下角在窗口和全屏布局中都可核对版本号。
