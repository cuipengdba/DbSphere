# DbSphere v4.8.0 多站点与代运维

- 中心按组织查看站点健康、事件编号和报告签收数量。可从中心打开原站点，同一事件关联采样和恢复记录。
- 站点摘要使用双向 TLS，中心记录采集覆盖、上报时间、断联和容量超限。站点持续在本地运行采集、告警和规则诊断。
- 站点委派给同组织值班员。升级记录支持批次顺序、实际运行版本核验和回退审计。
- 提供 Linux amd64 和 arm64 标准容器、Grafana 增强和原生 systemd 离线包及校验清单。
