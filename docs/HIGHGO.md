# 瀚高安全版 4.5.9 接入

DbSphere v2.1.0 支持将瀚高安全版数据库系统 V4.5.9 加入 PostgreSQL 类资产。实测兼容内核为 12.7，构建修订为 `63e6077`，测试环境为 CentOS 7.9 容器和 x86_64 数据库程序。厂商版本和兼容内核分别显示在资产采集能力中。

## 接入步骤

1. 由目标库管理员创建专用登录账号并按现场策略开放至 DbSphere 的连接。账号至少需要目标库的 `CONNECT` 权限。查看其他账号的等待、阻塞和 SQL 统计时，需要有效的 `pg_read_all_stats` 权限，通常由 `pg_monitor` 提供。瀚高安全版可启用三权分立，按现场账号和权限管理流程处理。[瀚高用户与身份管理](https://highgo.com/document/zh-cn/develop/user_identify.html)
2. 在 DbSphere 的「资产」中新增 PostgreSQL 类实例，填写地址、端口、目标库、专用账号及现场使用的 TLS 模式。隔离验收使用 MD5 认证。
3. 执行「立即采集」，核对资产的瀚高版本、连接结果、等待、锁、检查点和复制状态。需要 Top SQL 时，在目标库按现场变更流程配置 `pg_stat_statements`，并为采集账号开放相应统计。DbSphere 使用只读查询识别已有能力。

## 采集与诊断

- 使用兼容内核的统计视图读取连接、事务、会话等待、阻塞链、检查点、WAL 位置、复制、表和库容量。包含历史样本和短时等待捕获。
- 已启用 `pg_stat_statements` 时读取 Query ID、调用次数和执行耗时，用于 SQL 指纹统计。会话视图缺少 Query ID 和并行组长 PID，等待和阻塞按等待事件和实际会话 PID 追踪。
- 该内核没有 `pg_stat_wal`、`pg_stat_io` 和较新版本的部分明细列。采集能力页显示缺少的指标。未配置的复制通道或受权限限制的信号按实际状态展示。
- 采集结果、规则事件、阻塞证据与历史样本沿用独立 PostgreSQL 18 监控库。部署使用 DbSphere 的 Linux 离线包，目标端数据库由现场提供。
- 会话等待保留 PID、阻塞者 PID、应用及脱敏 SQL 指纹。上传原生日志并关联同一纳管实例后，从事件按 PID、指纹和时间查找证据。仅匹配 PID 和时间时，界面提示关联依据，供人工核对。
- 启用三权分立且采集账号缺少统计权限时，会话证据限定在该账号可见范围内。资产页面标明范围。

## 实库验收

在 CentOS 7.9 隔离容器中启动用户提供的瀚高数据目录。另外初始化独立测试库，用已授予 `pg_read_all_stats` 的专用只读账号完成采集和短时等待捕获。通过 DbSphere 资产入口演练真实锁等待，事件证据包含阻塞者与等待者的 PID。解除阻塞后原事件转为已恢复，故障样本和恢复样本均可从 PostgreSQL 18 读取。
